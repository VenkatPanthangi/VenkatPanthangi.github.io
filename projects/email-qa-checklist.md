# Email QA Checklist

Use this checklist for demonstration projects and approved campaign testing.

## Content and data
- [ ] Subject line and preheader reviewed
- [ ] Personalization tested with populated values
- [ ] Missing values and fallback content tested
- [ ] Conditional content paths tested
- [ ] Spelling, punctuation and legal copy reviewed

## HTML and rendering
- [ ] HTML validated
- [ ] Table structure and nesting reviewed
- [ ] Inline CSS checked
- [ ] Mobile viewport reviewed
- [ ] Images have appropriate alt text
- [ ] Images scale without distortion
- [ ] Buttons are readable and usable
- [ ] Dark-mode appearance reviewed
- [ ] Outlook-specific layout reviewed where applicable

## Links and tracking
- [ ] Every link destination checked
- [ ] CTA links checked
- [ ] Unsubscribe / preference links checked where required
- [ ] Tracking parameters reviewed
- [ ] No placeholder URLs remain

## Final approval
- [ ] Test send reviewed
- [ ] Rendering screenshots captured
- [ ] Changes documented
- [ ] Final approval recorded

Record actual client/device combinations tested. Do not claim compatibility with clients that were not tested.
