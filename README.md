# Email Developer Portfolio

A responsive, static portfolio starter for GitHub Pages, Netlify or Cloudflare Pages.

## Before publishing

1. Open `index.html`.
2. Replace `Your Name`, the email address, LinkedIn URL and GitHub URL placeholders.
3. Add a short, accurate professional summary and only claim experience you can substantiate.
4. Review each sample project and update it with your own tested examples.
5. Do not upload confidential client code, customer data, employer assets or proprietary campaign screenshots.
6. Check all links and test the site on desktop and mobile.

## Preview locally

Open `index.html` in a browser. For a local development server, you can use Python:
`python -m http.server 8000`

## Publish with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a public repository named exactly `YOUR-USERNAME.github.io`.
3. Upload the contents of this folder (not the ZIP file).
4. In repository Settings → Pages, choose the deployment source if prompted.
5. Wait for GitHub Pages to publish. The site address will be `https://YOUR-USERNAME.github.io/`.

GitHub's interface may change; consult its current Pages documentation:
https://docs.github.com/en/pages

## Project files

- `index.html` — portfolio homepage
- `css/styles.css` — responsive styles
- `projects/responsive-retail.html` — standalone HTML email demo
- `projects/dynamic-member-email.md` — AMPscript demonstration and test cases
- `projects/booking-confirmation.md` — transactional email concept
- `projects/email-qa-checklist.md` — QA checklist

This starter is a static website. The contact section uses a mailto link; it does not include a server-side contact form.
